## Operations

There is no new external service or key. The OCR worker handles both document and notebook queues. An opt-in `npm run seed:notebook` adds one clearly fictional printed notebook to the local Ayesha demo account without changing tasks.

Private originals and notebook derivatives use existing upload/OCR backup paths. A local database/upload backup preceded the schema update. No real Gmail account, WhatsApp account or student document folder was accessed for this delivery, and no external message was sent by the tests.
